Mettre à jour le site

La base du site n'est pas encore activée

Il faut créer le projet Supabase puis remplir le fichier config.js. La marche à suivre est dans le fichier LISEZMOI.md.

Pour modifier le site, connectez-vous avec l'adresse de l'association. Vous recevrez un lien par e-mail : il suffit de cliquer dessus.

Le lien arrive en une minute environ. Pensez à regarder dans les « Spams ».

Les bals, stages et réunions affichés dans l'agenda du site. Le prochain bal apparaît automatiquement dans « Les évènements », et on peut s'y inscrire depuis le site.

Affiche ou photo (facultatif)
